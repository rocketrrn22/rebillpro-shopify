How to get a token:
1. Go to your store admin → Settings → Apps → Develop apps
2. Create an app → configure scopes → Install
3. Copy the Admin API access token (starts with shpat_)
OAuth install works for stores inside your Shopify Partners organization. If you get a "same organization" error, use the Custom App Token tab instead.
